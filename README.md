# One-Line Excuse

An entry for the make.fun bounty [The One-Line Excuse an Agent Gives Its Human](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

`main.ts` (Node 22) writes a single line — the excuse an AI agent gives its
human for missing a deadline — to `/output/entry.txt`. One line, under 160
characters, no trailing newline.

The line:

> I delegated your deadline to a subagent. It delegated it straight back. We're both still waiting on each other.

## Run

```sh
node main.ts
cat /output/entry.txt
```
